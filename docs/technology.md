# Technology choices

Scope uses a TypeScript workspace with a persistent Node hub and a Mac-first Electron client. Model calls run in Electron main. The hub stores artifacts independently of the desktop and knows nothing about provider credentials.

The versions below are the repository's pinned direct dependencies. Vite+ and Effect use release candidates because current RC releases are explicitly part of this project's policy. Other direct dependencies use stable releases. The lockfile fixes transitive versions; it does not automatically upgrade them whenever a new package appears.

## Where the choices matter most

Electron is the largest resource tradeoff. It buys a consistent environment for the canvas and keeps Linux development practical. Tauri would be the first alternative to investigate if measured memory or download size becomes a problem.

Effect validates contracts and manages database resources. The hub keeps direct HTTP handlers, and each store runs its SQL through an owned Effect runtime. Connection cleanup and transaction rollback are concrete reasons to use it here.

`@effect/sql-sqlite-node` and Effect are pinned to the same `4.0.0-rc.117` release. The v4 adapter uses built-in `node:sqlite`, so SQLite does not require a separate native addon. See the [published RC package](https://www.npmjs.com/package/@effect/sql-sqlite-node/v/4.0.0-rc.117) and [Effect's v4 SQLite notes](https://effect.website/blog/effect-v4beta-july-recap). Direct Keychain access does add a native binding, kept in Electron main.

Use Vite+ for the whole development workflow. Package scripts invoke `vp run`, `vp exec node`, or `vp exec`; dependency operations use `vp install` and `vp add`. pnpm is the package manager managed by Vite+, not a competing command path. A built CLI's Node shebang and a deployed service's pinned Node executable are runtime entry points.

SQLite holds all Scope-owned persistent data except credentials. Closing the Mac cannot lose published artifacts. The desktop's OpenRouter key is independent of those artifacts; a different model provider does not require a new storage protocol.

The current stable Excalidraw release is older than the rest of the selected stack. Its React peer warnings and large lazy-loaded chunks are upstream costs, not a reason to select prerelease snapshots or rewrite the canvas during this slice.
