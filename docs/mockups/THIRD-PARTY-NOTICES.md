# Third-party notices

The study uses theme color values from Excalidraw and the Latin subset of its Comic Shanns font. It includes no Excalifont, Virgil, Assistant, or Font Awesome files. The interface uses installed system fonts. The HTML, CSS, diagram, and small control drawings were written for this study.

Sources are pinned to Excalidraw commit `afed9e6e27dd1cd5cc52857a405f7bea5312d813`.
